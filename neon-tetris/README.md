# NEON TETRIS · 现代俄罗斯方块

一个自包含的、零依赖的现代化浏览器版俄罗斯方块游戏。**单文件 `index.html`**，直接双击即可开玩（也可部署到 GitHub Pages / 任意静态服务器）。

> 综合了现代竞技俄罗斯方块的核心规则（Tetris Guideline），并加入了霓虹视觉、粒子特效、屏幕震动与程序化 Web Audio 音效与配乐。

## 🎮 现代特性（全部实装）

| 特性 | 说明 |
|------|------|
| **SRS 旋转 + 墙踢** | 实现完整的 Super Rotation System：8 个旋转状态、8×5 墙踢表（含 I 方块独立踢表、O 方块自旋），支持 T-Spin 与边角墙踢 |
| **7-Bag / 4-Bag / Classic / Random9G** | 可在「帮助」中切换随机器；默认 7-bag 保证方块发放公平、无长 drought |
| **Hold（持有）** | 一键暂存方块，随时换出（每落一次后不可再用） |
| **Next ×4** | 预览接下来的 4 个方块 |
| **Ghost Piece（幽灵块）** | 半透明预览落点 |
| **软降 / 硬降** | 软降（+1/格）与硬降（+2/格） |
| **DAS / ARR** | 自定义延迟自动重复，支持标准 / 快 / 关三档 |
| **Lock Delay（锁定时）** | 可开可关 |
| **分级重力** | 20 级重力递增，ms 累加器实现帧率无关 |
| **T-Spin 判定** | 按空角落数量（1/2/3）给出 1000/800/2000 × 等级加分 |
| **Perfect Clear（完美清除）** | 整列无空隙消除额外加分 |
| **Combo（连击）** | 连续消行额外加分，中断重置 |
| **高分保存** | 最高分存于 `localStorage` |

## 🎨 视觉 / 听觉

- **霓虹霓虹**：渐变高光 3D 方块、辉光描边、动态星空背景、青色边框
- **粒子特效**：消行时彩色粒子爆发，四消 / T-Spin 强化，满屏闪光
- **屏幕震动**：大消行时震动
- **消行动画**：闪烁 → 波前 → 满屏白光
- **程序化音效**：Web Audio API 合成，每种方块按颜色差异化音调；消行 / 旋转 / 硬降 / T-Spin / 升级 / 结束各有专属音型
- **动态配乐**：循环节拍（琶音 + 贝斯），速度跟随游戏节奏

## ⌨️ 操作

| 操作 | 键位 |
|------|------|
| 左移 / 右移 | `←` `→` / `A` `D` |
| 软降（加速下落） | `↓` / `S` / 空格 |

## 🚀 运行

1. 打开 `index.html`（或直接访问仓库的 raw/页面）
2. 点击「开始」即可
3. 建议用现代浏览器（Chrome / Firefox / Safari / Edge）

```bash
# 或用任意静态服务器部署（可选，方便分享）
cd neon-tetris
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000/neon-tetris/index.html
```

## 🛠️ 实现要点

- **分离关注点**：核心规则（方块数据、SRS 踢表、随机器、计分）与渲染（Canvas 2D）解耦
- **SRS 墙踢表**：严格采用 Tetris Guideline 的 8 状态 × 5 踢偏移（y 向下坐标）
- **性能**：`requestAnimationFrame` 主循环 + `ms` 累加器重力，粒子池动态管理，60fps 流畅
